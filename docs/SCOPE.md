# 课程反馈与访谈的智能分析需求与范围

## 已确定

- 核心目标是综合课程前、课程中和课程后的调查与访谈数据，对课程学习、教学内容组织、教学方式、训练实践及考核形式进行系统、有深度的文本分析与挖掘。
- 分析兼顾整体结构、群体差异、阶段变化、具体情境和反例，形成可回查材料的结论，支持学习策略、能力训练、项目实践与教学改进。
- 整体成果包含主题与编码、跨阶段比较、证据索引、必要可视化、方法复核和可执行的改进清单；原型支持查看分析结果与证据。
- 当前提供最初课堂调查的脱敏教学数据；学生可以开展组内访谈，补充具体过程与解释。
- 课前、课后的整体调查数据由教师提供；研究小组在课程进行中通过访谈等方式自行收集过程数据，整合三阶段材料并检验早期发现。
- 真实逐人材料受限使用；公开仓库提供去关联教学改写片段和格式说明。
- 当前已完成数据准备及项目任务说明，尚未实现分析应用。

## 第一轮可开展的工作

阅读数据和题目，选择一个问题，试做编码与主题比较；围绕不清楚之处开展课中访谈，可先在组内试访谈，再按研究问题补充不同经历的参与者。记录原文依据、反例、分歧和解释修订，逐步形成可复核的分析原型。具体访谈问题与使用方式见[项目任务与访谈安排](PROJECT_BRIEF.md)。

## 后续细化

- 确定首个分析功能、输出界面与交付形式。
- 选择人工基线、大模型辅助方法及对应评测。
- 明确可用模型服务、计算资源，以及三个阶段的数据覆盖、问题可比性、获准使用的关联标识和完整全班数据字段。
- 根据试分析与访谈反馈调整范围，不预设所有材料都必须归入固定标签。
